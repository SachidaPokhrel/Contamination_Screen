# fcs

Independent public-genome FCS-GX case: GCA_051997085.1, Globisporangium irregulare strain 13-30. The user reports an NCBI contamination flag; exact wording was not independently retrieved. Original input, cleaned/excluded FASTAs and completed HPC reports are retained. This is distinct from both original SRA readsets. Portable screen/clean wrappers use config.json; see docs/15_fcs_linux.md.
